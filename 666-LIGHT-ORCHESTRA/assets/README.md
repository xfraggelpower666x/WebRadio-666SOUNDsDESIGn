# LIGHT ORCHESTRA branding assets

This folder is intentionally asset-safe.

The Control Center automatically loads one of these verified owner-provided files when present:

- `LOS_APP_ICON.ico`
- `LOS_APP_ICON.png`

No synthetic placeholder is committed as the official logo. Add the original approved asset bytes only.

PyInstaller/package workflows may copy this folder into the Windows package when it exists.
