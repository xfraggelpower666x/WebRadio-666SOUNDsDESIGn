The WebRadio repository release checker intentionally rejects nested ZIP files.
Therefore the structure-control systemsicherung is generated by CI and uploaded
as a repository Actions artifact. Only the artifact manifest/receipt belongs in
the repository source tree.

A valid freeze requires:
1. exact source commit recorded;
2. allowed-path audit PASS;
3. repository Release Integrity PASS;
4. structure-control manifest hashes PASS;
5. ZIP CRC PASS;
6. artifact upload PASS;
7. no deployment action;
8. no production radio runtime mutation.
