666SOUNDsDESIGn — ROOT MIGRATION REPAIR v1

Zweck:
- external-player wird als Hauptplayer in Root verlagert.
- Kein Design-Umbau, kein Boost, kein EQ, kein DSP.
- /internal bleibt Notfallplayer im Worker.
- /extern und /external-player bleiben Alias auf den Root-Hauptplayer.
- Browser bleibt auf der eigenen Domain.

Verlagert:
- external-player/index.html -> index.html
- external-player/css/*.css -> css/*.css
- external-player/js/*.js -> js/*.js
- external-player/assets/images/* -> assets/images/*

Gesichert:
- überschriebenen Root-Dateien wurden unter __legacy_before_root_migration/ abgelegt.

Geändert:
- worker.js EXTERNAL_PLAYER_URL zeigt auf GitHub-Pages-Root statt /external-player/
- worker.js proxyt /css/*, /js/*, /assets/* für den Root-Hauptplayer
- /internal, /stream, /fallback-stream, /api/nowplaying, /health bleiben erhalten
