SAME URL FIX

Purpose:
- Keep player separated in repo files.
- Avoid broken extra-path delivery on the public URL.
- Serve CSS/JS/CONFIG through the same root URL using query markers.

New runtime URLs:
- /           -> index.html
- /?asset=css -> css/main.css content
- /?asset=js  -> js/app.js content
- /?asset=config -> config/stream.config.js content
