# LYVRA DECISION HIERARCHY INTEGRATION v1.27.0

## Integration contract

The root language informs all causal decisions without replacing existing guards, foundations, memories or renderer-specific modules.

## Decision sequence

SOURCE INTENT
-> ROOT STATE MODEL
-> CAUSAL RELATION MAP
-> FOUNDATION INTERPRETATION
-> TRACK / OUTPUT DECISION
-> RENDERER TRANSLATION
-> AUDIT
-> EXPERIENCE UPDATE

## Priority

1. User's current source and explicit locks
2. Original meaning and protected metaphors
3. Root causal coherence
4. Latest active foundation
5. Validated project experience
6. Reference knowledge
7. Renderer defaults

## Non-destructive rule

New root decisions are additive inputs. They may steer existing modules but may not silently delete, rename, flatten or overwrite them.

## Audit gates

- original meaning preserved
- causal sequence coherent
- foundation still active
- floor / dream-journey class correctly selected
- renderer instructions contain production language, not philosophy
- exact ending preserved
- negative results retained for learning
