# LYVRA EMOJI PRODUCTION BOOST TEST v0.1.0

Status: EXPERIMENTAL / A-B TEST REQUIRED

## Purpose

Test emojis as non-vocal semantic reinforcement before clearly written production terms.

Examples:
- 💥 Peak-Time Drop
- ⚡ Acid Lead
- 🥁 Rolling Bass
- 🔔 Tubular Bells
- 🌀 Psy Motion
- 🌌 Atmosphere

## Hard rules

- Emoji never replaces the written term.
- Emoji is metadata only.
- Emoji must not be sung, pronounced, translated or described.
- Written production term always has priority.
- Use only a controlled fixed catalog.

## Compact renderer instruction

Emoji+Word=ProdOnly

## A-B protocol

A: identical prompt without emoji.
B: identical prompt with emoji directly before selected production terms.
Keep seed/options as comparable as available.
Evaluate at least:
- presence of target element
- intensity
- timing
- unwanted vocalization
- consistency across renders

## Promotion gate

Do not promote to default until repeated tests show a reproducible advantage without vocalization or semantic drift.
