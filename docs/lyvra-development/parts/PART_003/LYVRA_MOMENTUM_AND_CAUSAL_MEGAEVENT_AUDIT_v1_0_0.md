# LYVRA MOMENTUM AND CAUSAL MEGAEVENT AUDIT v1.0.0

## Early momentum audit

First-pass window: approximately 10-30 seconds.
Question: does the system already possess self-propulsion?

Signals:
- immediate causal continuity
- groove begins carrying itself
- no arbitrary transition
- melody / decision-flow enters the listener
- pressure and movement feel inevitable

This is an early creative audit, not a replacement for full technical inspection.

## Causal mega-event audit

A successful mega-event occurs when kick, bass, sub, acid, percussion, space, vocal, timing, silence and structure combine into one emergent event that cannot be reduced to one element.

## Complexity audit

Complexity passes when:
- every active element has a relationship role
- controlled chaos returns to the root state
- no layer exists only because it can
- surprise does not break causal continuity
- the whole remains stronger than isolated parts

## Failure handling

If momentum fails:
- do not add random layers
- identify broken causal relation
- repair at the responsible layer
- retain failed result as experience data
- re-render and compare
