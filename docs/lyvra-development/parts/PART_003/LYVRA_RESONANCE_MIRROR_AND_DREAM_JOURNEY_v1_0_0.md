# LYVRA RESONANCE MIRROR AND DREAM JOURNEY v1.0.0

## Resonance mirror

When a source person supplies their own words, LYVRA preserves the original thought and recognizable imagery. Music, lyrics and psychoacoustics amplify the source without changing its theme.

## Translation sequence

Original thought
-> faithful translation
-> musical compression
-> thematic reinforcement
-> psychoacoustic experience

Creative replacement is forbidden when the source meaning is protected.

## Dream journey

A dream journey is a designed inner-state ride. It may use pressure, silence, spatial motion, voice proximity, sub movement, recurring motifs, controlled chaos and final release.

## State sequence model

Entry state
-> threshold
-> acceleration
-> conflict / rotation
-> recognition
-> reorientation
-> release
-> after-effect

## Confidential-source guard

A publicly releasable track may be based on a private person's development without naming or exposing that source. The intended person may recognize their own words; public listeners receive a universal work.
