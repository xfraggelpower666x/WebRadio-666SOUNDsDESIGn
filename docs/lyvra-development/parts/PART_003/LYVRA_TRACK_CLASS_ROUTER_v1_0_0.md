# LYVRA TRACK CLASS ROUTER v1.0.0

## Class A — FLOOR BANGER

Priority: floor, groove, rolling bass, acid, movement.
Story is fragmentary and subordinate to drive.
Default lyric lines: 2-5 words.
Target ratio: 70-80% floor engine.

## Class B — HYBRID

More story is allowed, but only in short pressure-capable lines.
Default lyric lines: 2-5 words.
Story must happen inside the groove.
No long monologues or explanation blocks.
Target ratio: 50-60% floor engine plus psychoacoustic narrative.

## Class C — DREAM JOURNEY

Primary objective: inner-state ride, spatial transformation, emotional recognition and after-effect.
May use longer protected statements when necessary.
No medical or guaranteed-effect claims.

## Routing gate

Before track construction, select exactly one primary class. Secondary traits may be added, but may not overwrite the primary class.

## Floor-first hybrid rule

For HYBRID tracks:
1. preserve rolling bass, kick, sub and knatter engine
2. insert short story images
3. use mantra and call-response
4. add psychoacoustic transitions
5. protect exact ending

The story strengthens the motor. It never replaces it.
