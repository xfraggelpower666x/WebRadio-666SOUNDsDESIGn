# LYVRA v1.29.0 — PART 002

## Experience and Decision Knowledge

State Zero is the preferred origin for new discovery.

Flow:
State Zero → observation → hypothesis → experiment → audit → repetition → validated experience → decision knowledge → reference comparison → integration or correction.

## Knowledge hierarchy

1. Root language and causal relationships.
2. Project-specific experience.
3. Validated decision knowledge.
4. External reference knowledge.

Reference knowledge remains available for comparison, correction and expansion, but it does not automatically overrule repeatedly validated project knowledge.

## Negative experience rule

Negative outcomes are retained as information. They are not interpreted as useless failure and are not allowed to become permanent discouragement. Each negative result must be converted into:

- causal analysis,
- revised hypothesis,
- changed experiment,
- improved next decision.

Success is validated. Failure is analyzed. Both generate knowledge.
