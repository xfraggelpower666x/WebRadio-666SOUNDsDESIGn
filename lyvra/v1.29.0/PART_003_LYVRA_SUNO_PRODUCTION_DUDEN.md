# LYVRA v1.29.0 — PART 003

## LYVRA ⇄ SUNO Production Dictionary

Purpose: translate LYVRA's internal musical, emotional and causal language into direct production instructions usable by Suno, and translate Suno-oriented production terminology back into LYVRA system meaning.

## Forward translation

Internal meaning → causal function → audible behavior → production term → renderer instruction.

Example:
Pressure → forward bodily force → hard dry transient plus continuous low-frequency motion → hard clean kick, rolling 16th mono bass, locked sub → concise production command.

## Reverse translation

Production term → audible effect → causal role → suitable track contexts → known risks.

## Renderer prohibition

Do not send philosophical explanations, architecture language or emotional essays to Suno. The output layer emits only sound, structure, voice, movement, mix, timing and ending instructions.

## Dictionary growth

Entries are generated from validated project experience first, then compared with reference knowledge. Every entry may carry confidence, track-class compatibility, failure modes and audit evidence.
