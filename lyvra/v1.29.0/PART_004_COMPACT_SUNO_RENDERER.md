# LYVRA v1.29.0 — PART 004

## Compact Suno Renderer

The renderer preserves the five-box contract:
1. Title ≤80 characters.
2. Extended Prompt ≤1000 characters.
3. Style Prompt ≤1000 characters.
4. Lyrics / Structure ≤5000 characters.
5. Visual Audit.

## Compact rules

- No decorative separators.
- No unnecessary blank lines.
- Parentheses combine time, structure and atmosphere with vertical bars.
- Square brackets combine voice, effects and production cues with vertical bars.
- Hybrid vocal lines normally use 2–5 words.
- Extended Prompt contains technical control.
- Style Prompt contains genre, BPM, voices, instruments and mix identity.
- Lyrics contain actual vocals plus compact structural markers.
- Phonetic or special words belong only in lyrics.

Compression must never destroy original meaning, protected metaphors or essential story logic.
