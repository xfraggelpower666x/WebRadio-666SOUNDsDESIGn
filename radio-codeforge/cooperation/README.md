
## R03: source-pinned GitHub host adapter (nonproduction)

`github-readonly-host.mjs` accepts only explicit callable `fetchFile` and `fetchBlob` host handles, an immutable commit and expected blob SHA per allowlisted file, the exact native commit, authorized read-only host receipt, and a fixed repository allowlist. The returned file payload is validated by Git object SHA-1 and compared against a separately fetched blob payload. A mismatch fails closed. This adapter never creates GitHub API credentials, never uses global fetch, and has no mutation method.

The connector itself must be supplied by the authorized ChatGPT host. Local tests use real callback invocation with in-memory provider stubs, **not** a live plugin connection. Independent tool-backed GitHub source readback may be performed in the chat, but proves only source inspection, not that an external LYVRA/CLIC peer plugin executed. Neither R02 nor R03 auto-activates foreign peers.
