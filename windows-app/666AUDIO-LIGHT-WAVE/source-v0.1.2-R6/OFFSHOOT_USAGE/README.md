## Repair R1

Start either server locally with `python server.py --media-root PATH` (or `server2.py`). Use the printed loopback address. Only known pages and cataloged media are served. Media symlinks may resolve within the selected root.

An offshoot project that utlizes the same signal base for other purposes: autoscrolling image/video feed (used in VR or in Ultra-Wide 3440x1440... any resolution can be used though...)
